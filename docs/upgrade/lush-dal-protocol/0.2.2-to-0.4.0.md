# lush-dal-protocol 0.2.2 → 0.4.0 升级指南

## 版本变更

| 项目 | 旧版本 | 新版本 |
|------|--------|--------|
| lush-dal-protocol | 0.2.2 | 0.4.0 |

## 破坏性变更

### 1. `Base*` 协议重命名为 `Dto*`

所有 `Base*` 前缀的 DAL 协议类已重命名为 `Dto*` 前缀, 以消除与 Pydantic `BaseModel` 的命名混淆.

| 旧名称 | 新名称 |
|--------|--------|
| `BaseSyncReadDAL` | `DtoSyncReadDAL` |
| `BaseAsyncReadDAL` | `DtoAsyncReadDAL` |
| `BaseSyncWriteDAL` | `DtoSyncWriteDAL` |
| `BaseAsyncWriteDAL` | `DtoAsyncWriteDAL` |
| `BaseSyncBaseDAL` | `DtoSyncDAL` |
| `BaseAsyncBaseDAL` | `DtoAsyncDAL` |

**迁移步骤：**

```python
# 旧方式
from lush_dal_protocol import BaseSyncReadDAL, BaseAsyncBaseDAL

class MyDAL(BaseSyncReadDAL[SessionT, EntityT, DTOModelT, PrimaryKeyT]):
    ...

# 新方式
from lush_dal_protocol import DtoSyncReadDAL, DtoAsyncDAL

class MyDAL(DtoSyncReadDAL[SessionT, EntityT, DTOModelT, PrimaryKeyT]):
    ...
```

### 2. 测试 mixin 重命名

一致性测试 mixin 也跟随重命名:

| 旧名称 | 新名称 |
|--------|--------|
| `BaseSyncReadDALConformanceTests` | `SyncReadDALConformanceTests` (不变) |

> 注意: Entity* 前缀的 conformance 测试 mixin 名称不变.

**新增** Dto* conformance 测试套件 (见下方"新特性").

### 3. 文件重命名

| 旧路径 | 新路径 |
|--------|--------|
| `abc/base_read.py` | `abc/dto_read.py` |
| `abc/base_write.py` | `abc/dto_write.py` |
| `abc/base_composed.py` | `abc/dto_composed.py` |
| `testing/base_conformance.py` | `testing/dto_conformance.py` |

> 如果你直接从子模块路径导入 (如 `from lush_dal_protocol.abc.base_read import ...`), 需要更新为新路径.

## 新特性

### Dto* 协议层

新增无需 `EntityT` 的 DAL 协议, 适用于 Core DAL / 非 ORM 场景:

- `DtoSyncReadDAL` / `DtoAsyncReadDAL` — 只读协议, 直接返回 DTO
- `DtoSyncWriteDAL` / `DtoAsyncWriteDAL` — 写入协议
- `DtoSyncDAL` / `DtoAsyncDAL` — 组合协议 (Read + Write)

```python
from lush_dal_protocol import DtoSyncDAL

class MyCoreDAL(DtoSyncDAL[DTOModelT, CUModelT]):
    """无 ORM 实体绑定, 直接操作 DTO."""
```

### 哨兵类型

新增 `NoSession` / `NoEntity` 占位类型及对应单例 `NO_SESSION` / `NO_ENTITY`:

```python
from lush_dal_protocol import NoSession, NO_SESSION

# session 为可选参数, 默认不绑定
class MyDAL(DtoSyncReadDAL[MyDTO, int]):
    def get_by_id(self, entity_id, *, session=NO_SESSION): ...
```

### Dto* Conformance 测试套件

新增 `DtoSyncConformanceTests` / `DtoAsyncConformanceTests` 等 mixin, 用于验证 Dto* 协议实现:

```python
from lush_dal_protocol.testing import DtoSyncFullConformanceTests

class TestMyCoreDAL(DtoSyncFullConformanceTests):
    @pytest.fixture
    def dal(self): return MyCoreDAL(...)
```

## 降级/回退

如需回退到 0.2.2:

```toml
# pyproject.toml
[project]
dependencies = [
    "lush-dal-protocol>=0.2.2,<0.4.0",
]
```

或使用 uv:

```bash
uv pip install 'lush-dal-protocol>=0.2.2,<0.4.0'
```
