# lush-sentryx 0.2.2 → 0.3.0 升级指南

## 版本变更

| 项目 | 旧版本 | 新版本 |
|------|--------|--------|
| lush-sentryx | 0.2.2 | 0.3.0 |
| lush-sentryx-core (依赖) | ≥0.1.1 | ≥0.2.0 |

## 破坏性变更

### 删除 `scrub_business_sensitive_fields` 配置参数

`sentryx_init()` 中的 `scrub_business_sensitive_fields` 参数已删除。
现在通过 `create_enhanced_scrubber(denylist=...)` 直接传入业务敏感字段。

**迁移步骤：**

```python
# 旧方式 (已删除)
import lush_sentryx
lush_sentryx.sentryx_init(
    dsn="...",
    scrub_business_sensitive_fields=True,  # 已删除
)

# 新方式 (推荐)
from lush_sentryx import create_enhanced_scrubber
import sentry_sdk

# 1. 创建清理器，传入业务敏感字段
scrubber = create_enhanced_scrubber(
    denylist={"custom_secret", "internal_token", "api_key"}
)

# 2. 初始化 Sentry SDK
sentry_sdk.init(
    dsn="...",
    event_scrubber=scrubber,
)
```

```toml

dependencies = [
```
